Methodology — Multi Depot

Core algorithm: Weighted Geometric Median

The point that minimises the sum of demand-weighted distances to all demand points, found by iterative Weiszfeld refinement (start at the weighted average, reweight by 1/distance, repeat until the move is below tolerance).

Multiple Depots

solve_multiple_depots()
  1. Project to local metres; run 10 demand-weighted KMeans starts (k-means++, one init per seed).
  2. Refine each start by alternating location-allocation: assign to nearest depot, relocate each depot to its cluster's weighted geometric median, until the objective settles.
  3. Keep the start with the lowest objective; report per-depot metrics.
k depots, each serving a geographic cluster, spreading load across facilities.

Key features

  • Equirectangular projection to local metres for geodetic accuracy.
  • Demand weighting throughout (clustering and medians).
  • Iterative refinement with tolerance-based convergence.
